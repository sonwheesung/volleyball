> 메커니즘(스킬 §1.1): 새 개발자 계정 안 만든다. **새 "조직" 결제 프로필 생성(D-U-N-S 필수) → 검증 → 기존 계정에 연결.** 기존 프로필의 계정 유형 자체는 수정 불가하지만 이 방식으로 전환됨.

1. Play Console → 좌측 **개발자 계정** → **계정 세부정보** (`.../account/developer-details`).
2. **계정 유형**(현재: 개인) 영역에서 **조직으로 변경/전환** 진입. (또는 **설정 → 결제 프로필**에서 조직 프로필 생성 경로.)
